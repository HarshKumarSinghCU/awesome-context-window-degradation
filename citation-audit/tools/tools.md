# Long-Context Tools & Libraries

1. **vLLM**: PagedAttention serving system (https://github.com/vllm-project/vllm)
2. **FlashAttention**: IO-aware attention acceleration (https://github.com/Dao-AILab/flash-attention)
3. **Needle-In-A-Haystack**: Evaluator for long contexts (https://github.com/gkamradt/needle-in-a-haystack)
4. **Transformers**: Hugging Face implementation of RoPE/YaRN (https://github.com/huggingface/transformers)
5. **FastChat**: Platform for long-context chatbot evaluation (https://github.com/lm-sys/FastChat)
